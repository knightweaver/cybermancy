# Cybermancy v0.1.14

Patch release updating Daggerheart system compatibility metadata for the final
Foundry 13 / Daggerheart 1.x Cybermancy baseline.

## Compatibility

- Foundry VTT 13
- Daggerheart minimum 1.2
- Daggerheart verified 1.2
- Daggerheart maximum 1.9

## Changes from v0.1.13

- Expands the declared Daggerheart 1.x compatibility range from the prior
  major-only metadata to the supported 1.2 through 1.9 range.
- No Cybermancy rules, Compendium content, runtime scripts, assets, or Foundry
  mechanics are changed by this patch.

The runtime candidate is rebuilt and validated through the same deterministic
release pipeline used for v0.1.13.
