# Cybermancy Adversary Design Guide

## Purpose

This document defines the design principles, balance guidelines, feature selection philosophy, and narrative conventions used when creating Cybermancy adversaries.

The goal is not simply to create monsters. Adversaries should create interesting tactical situations, reinforce the narrative, and feel like natural inhabitants of the Cybermancy setting.

---

# Core Design Philosophy

Cybermancy encounters should be built around:

1. Distinct battlefield roles
2. Interesting feature interactions
3. Narrative identity
4. Environmental storytelling
5. Fear generation rather than raw damage

Players should remember:

* what the adversary did
* how it changed the battlefield
* how it fit the story

More than how much damage it dealt.

---

# Adversary Categories

## Minions

Purpose:

* Generate pressure
* Consume actions
* Create Fear
* Support stronger enemies

Characteristics:

* Very low durability
* Simple feature combinations
* Usually appear in groups

Examples:

* Raz Eels
* Security Drones
* Swarm Creatures

Recommended Features:

* Horde
* Momentum
* Paralyzing Shock
* Pack-oriented abilities

Avoid:

* Complex tactical features
* Leadership features

---

## Standard Adversaries

Purpose:

* Core encounter backbone

Characteristics:

* Reliable damage
* Limited complexity
* Usually encountered in groups

Examples:

* Mireborn Thralls
* Security Guards
* Cultists

Recommended Features:

* Strike as One
* Momentum
* Terrifying
* Relentless

---

## Elites

Purpose:

* Battlefield anchors
* Tactical disruption

Characteristics:

* Higher durability
* Multiple features
* Distinct role

Examples:

* Pierjaw Crab
* Heavy Security Operative
* Mutated Enforcer

Recommended Features:

* Goading Strike
* Ground Slam
* Clear the Decks
* Immovable Object
* Relentless

Avoid:

* Excessive support abilities
* Commander features unless narrative demands it

---

## Leaders

Purpose:

* Coordinate enemies
* Generate Fear economy
* Change encounter flow

Characteristics:

* Support-focused
* Moderate durability
* Force multipliers

Examples:

* Runner Team Leaders
* Gang Bosses
* Cult Priests

Recommended Features:

* Tactician
* Rally Guards
* Focused Volley
* Move as a Unit

---

## Solos

Purpose:

* Entire encounter revolves around them

Characteristics:

* High durability
* Strong Fear actions
* Multiple encounter phases

Examples:

* Experimental Chimera
* Corporate War Machine
* Ancient Resonance Entities

Guidelines:

* Never rely solely on HP.
* Must change battlefield conditions.
* Must possess at least one signature ability.

---

# Feature Selection Philosophy

## Battlefield Control Features

Use when adversary should reposition players.

Examples:

* Ground Slam
* Clear the Decks
* Knockback-style effects

Best For:

* Large creatures
* Vehicles
* Brutes

---

## Coordination Features

Use when adversary functions as part of a group.

Examples:

* Strike as One
* Tactician
* Rally Guards
* Move as a Unit

Best For:

* Corporate teams
* Military units
* Hive-minded creatures

---

## Fear Economy Features

Use when adversary should escalate encounters.

Examples:

* Momentum
* Terrifying
* Reality Quake

Best For:

* Elite threats
* Narrative villains

---

## Defensive Features

Use sparingly.

Examples:

* Immovable Object
* Defensive reactions

Defenses should create decisions.

Defenses should not simply prolong combat.

# Encounter Composition

For a 4-player Tier 1 party:

Easy:

* 1 Elite
* 2 Standards

Moderate:

* 1 Elite
* 4 Standards

Hard:

* 1 Elite
* 4 Standards
* Several Minions

Boss Encounter:

* 1 Solo
* Supporting Standards or Minions

---

# Encounter Design Rule

Every encounter should answer:

1. What is the battlefield problem?
2. What feature creates that problem?
3. What player role is challenged?
4. What story element does this reinforce?

If an adversary only contributes damage, redesign it.

If an adversary contributes a memorable tactical situation, keep it.

---

# Cybermancy Tone

Adversaries should feel like products of the world.

A creature is never merely a monster.

It should tell a story about:

* The Resonance Cascade
* The Council
* The Cabal
* Corporate experimentation
* Human ambition
* Psychic transformation
* The cost of changing reality

The best adversaries reveal setting lore through their existence.
