# Step 3 Class Package publication contract

Chapter 12 is the primary publication location for both canonical structured families:

```text
family:classes
family:subclasses
```

The families remain distinct canonical inputs. Step 3 does not flatten or duplicate their data. Instead it declares one publication composition:

```text
Chapter 12 — Classes and Subclasses
    Class
        full linked Subclass structures
```

Step 4 must resolve each Subclass to exactly one Class and expose that relationship deterministically. Step 6 then composes the normalized records so the full Subclass progression appears beneath its Class rather than in a standalone Subclass reference chapter.

There is intentionally no independent Chapter 13 node. Chapter number 13 is reserved; Chapters 14-23 keep their accepted numbers, preserving the existing Domains, Feature Reference, and Equipment regression baselines.
