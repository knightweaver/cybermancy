## Features
### Eclipse Wall

The world outside goes silent—you’re inside the machine now.

The cognitive dissonance created by interacting with this ICE results in -2 on Evasion until you break this subroutine or disengage from the Device.

- **Eclipse Wall** (*Action*) — The world outside goes silent—you’re inside the machine now.

Cuts external connections; you are alone until it drops.

### Paralyzing Shock

Mark a Stress to make a standard attack against all targets within Very Close range. You gain a Fear for each target that marks HP.
