# Sleaze Gate
<img src="../../../assets/icons/features/sleaze-gate.webp" alt="Sleaze Gate" class="item-image" style="width:300px; height:auto;">
## Description
*<p><em>The easiest path is always the one that bites.</em><br /><br /></p><p class="Card-Feature">Any device with this ICE on it presents itself as Unhardened.  Upon the first attempt by a hacker to take a Control action, the device re-presents itself as Hardened and the hacker must, as a Reaction, make an immediate Spellcasting (Hacking) check with a Difficulty +2.  The outcomes are:</p><p></p><ul><li><p>Critical success: the ICE is deactivated no other consequences.</p></li><li><p>Success with Hope: No negative effects, but the ICE is still active and must be disabled before any Control action can be taken.</p></li><li><p>Success with Fear: Mark 1 Stress and the ICE is still active and must be disabled before any Control action can be taken.</p></li><li><p>Failures: the ICE is still active and must be disabled before any Control action can be taken.  </p><ul><li><p>Advance the System alert by 2. </p></li><li><p>All Spellcasting (Hacking) attempts are at -2 for the remainder of the Scene</p></li><li><p>There is a tracker installed on your computer and removing this required the expendature of a Long Rest downtime activity.</p></li></ul></li></ul>*
