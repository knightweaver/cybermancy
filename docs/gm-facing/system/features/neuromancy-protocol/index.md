## Description
*<p>Spellwork and software share the same bus. </p><p>After you succeed on a Spellcast roll using an Arcana card, you may immediately take an additional action to perform a Circuit-domain hack or Circuit feature you have access to. </p><p>This follow-up action does not cost Hope (if it normally would), but it can still have other costs (like marking Stress) and it must target the same system, scene, or opposition when reasonable.</p>*
