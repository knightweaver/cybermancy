# Pawning the Past
<img src="../../../assets/icons/features/pawning-the-past.webp" alt="Pawning the Past" class="item-image" style="width:300px; height:auto;">
## Description
*<p>You run a regression trace on a person’s timeline and spin up a “backup” memory state. </p><p>Once per session, you may touch (or establish a secure comms link to) a willing creature and implant a false but plausible memory of a single recent event (no longer than a few minutes of lived experience). </p><p>The memory feels real for 1028 seconds and then degrades over the next day; afterward, the target retains two conflicting recollections. The GM decides what concrete details can be changed, but this feature cannot erase oaths, remove Conditions, or undo harm—only alter what the target believes happened.</p>*
