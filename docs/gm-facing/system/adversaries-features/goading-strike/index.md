# Goading Strike
<img src="../../../assets/icons/adversaries-features/goading-strike.webp" alt="Goading Strike" class="item-image" style="width:300px; height:auto;">
## Description
*<p>Make a standard attack against a target. On a success, <strong>mark a Stress</strong> to Taunt the target until their next successful attack. The next time the Taunted target attacks, they have disadvantage against targets other than the Weaponmaster.</p>*
