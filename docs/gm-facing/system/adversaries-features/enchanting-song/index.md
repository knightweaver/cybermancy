# Enchanting Song
<img src="../../../assets/icons/adversaries-features/enchanting-song.webp" alt="Enchanting Song" class="item-image" style="width:300px; height:auto;">
## Description
*<p><strong>Spend a Fear</strong> to sing a song that affects all targets within Close range. Targets must succeed on an Instinct Reaction Roll or become Entranced until they mark 2 Stress. Other Sirens within Close range of the target can <strong>mark a Stress</strong> to each add a +1 bonus to the Difficulty of the reaction roll. While Entranced, a target can’t act and is <em>Vulnerable</em>.</p><p>@Template[type:emanation|range:c]</p>*
