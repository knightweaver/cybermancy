# Pick Off the Straggler
<img src="../../../assets/icons/adversaries-features/pick-off-the-straggler.webp" alt="Pick Off the Straggler" class="item-image" style="width:300px; height:auto;">
## Description
*<p><strong>Mark a Stress</strong> to cause a target within Melee range to make an Instinct Reaction Roll. On a failure, the target must mark 2 Stress and is teleported with the Fang to a shadow within Far range, making them temporarily Vulnerable. On a success, the target must mark a Stress.</p>*
