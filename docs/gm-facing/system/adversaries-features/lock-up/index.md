# Lock Up
<img src="../../../assets/icons/adversaries-features/lock-up.webp" alt="Lock Up" class="item-image" style="width:300px; height:auto;">
## Description
*<p><strong>Mark a Stress</strong> to make an attack against a target within Very Close range. On a success, the target is <em>Restrained</em> within the Gaoler until freed with a successful Strength Roll (18). While <em>Restrained</em>, the target can only attack the Gaoler. </p>*
