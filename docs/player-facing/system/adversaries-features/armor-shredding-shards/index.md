# Armor-Shredding Shards
<img src="../../../assets/icons/adversaries-features/armor-shredding-shards.webp" alt="Armor-Shredding Shards" class="item-image" style="width:300px; height:auto;">
## Description
*<p>On a successful attack within Melee range against the Snake, the attacker must mark an Armor Slot without receiving its benefits (they can still use armor to reduce the damage). If they can’t mark an Armor Slot, they must mark an additional HP.</p>*
