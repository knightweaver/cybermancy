# Spitter
<img src="../../../assets/icons/adversaries-features/spitter.webp" alt="Spitter" class="item-image" style="width:300px; height:auto;">
## Description
*<p><strong>Spend a Fear</strong> to introduce a <strong>d6</strong> Spitter Die. When the Snake is in the spotlight, roll this die. On a result of 5 or higher, all targets in front of the Snake within Far range must succeed on an Agility Reaction Roll or take <strong>1d4</strong> physical damage. The Snake can take the spotlight a second time this GM turn.</p><p>@Template[type:inFront|range:f]</p>*
