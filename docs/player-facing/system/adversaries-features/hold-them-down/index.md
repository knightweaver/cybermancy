# Hold Them Down
<img src="../../../assets/icons/adversaries-features/hold-them-down.webp" alt="Hold Them Down" class="item-image" style="width:300px; height:auto;">
## Description
*<p>Make an attack against a target within Melee range. On a success, the target takes no damage but is Restrained and <em>Vulnerable</em>. The target can break free, clearing both conditions, with a successful Strength Roll or is freed automatically if the Kneebreaker takes Major or greater damage.</p>*
