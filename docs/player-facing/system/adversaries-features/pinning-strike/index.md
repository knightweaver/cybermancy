# Pinning Strike
<img src="../../../assets/icons/adversaries-features/pinning-strike.webp" alt="Pinning Strike" class="item-image" style="width:300px; height:auto;">
## Description
*<p>Make a standard attack against a target. On a success, you can <strong>mark a Stress</strong> to pin them to a nearby surface. The pinned target is <em>Restrained</em> until they break free with a successful Finesse or Strength Roll.</p>*
