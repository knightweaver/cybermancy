# Fall Back
<img src="../../../assets/icons/adversaries-features/fall-back.webp" alt="Fall Back" class="item-image" style="width:300px; height:auto;">
## Description
*<p>When a creature moves into Melee range to make an attack, you can <strong>mark a Stress</strong> before the attack roll to move anywhere within Close range and make an attack against that creature. On a success, deal <strong>1d10+2</strong> physical damage.</p>*
