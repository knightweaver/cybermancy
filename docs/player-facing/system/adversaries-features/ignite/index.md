# Ignite
<img src="../../../assets/icons/adversaries-features/ignite.webp" alt="Ignite" class="item-image" style="width:300px; height:auto;">
## Description
*<p>Make an attack against a target within Very Close range. On a success, the target takes <strong>1d8</strong> magic damage and is Ignited until they’re extinguished with a successful Finesse Roll (14). While Ignited, the target takes <strong>1d4</strong> magic damage when they make an action roll.</p>*
