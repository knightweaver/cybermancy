# Deadly Drop
<img src="../../../assets/icons/adversaries-features/deadly-drop.webp" alt="Deadly Drop" class="item-image" style="width:300px; height:auto;">
## Description
*<p>While flying, the Eagle can drop a Restrained target they are holding. When dropped, the target is no longer Restrained but starts falling. If their fall isn’t prevented during the PCs’ next action, the target takes <strong>2d20</strong> physical damage when they land.</p>*
