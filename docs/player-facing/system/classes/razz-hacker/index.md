# Razz Hacker
<img src="../../../assets/icons/classes/razz-hacker.webp" alt="Razz Hacker" class="item-image" style="width:300px; height:auto;">

## Description
*<p>The world calls them Razz Hackers. They call themselves Neo Monks—adepts who treat spellwork and software as the same living language running beneath neon streets and astral skylines.</p><p>Nobody teaches you how to become a Razz Hacker. You learn it the hard way: by realizing magic and code aren’t opposites or “two paths.” They are the same interface—syntax that convinces reality to compile.</p><p>Once it clicks, you move through the world differently: you slip through an ICE wall as a freezing sigil in the datasphere, or you fire an arcane pulse packaged as perfectly structured JSON.</p><p></p>*

## At a Glance
- **Domains:** Arcana, Circuit
- **Hit Points:** 5
- **Evasion:** 11
