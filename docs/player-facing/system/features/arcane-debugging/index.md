# Arcane Debugging
<img src="../../../assets/icons/features/arcane-debugging.webp" alt="Arcane Debugging" class="item-image" style="width:300px; height:auto;">
## Description
*<p>You patch reality like bad code. </p><p>At the start of each session, gain a number of Debug Tokens equal to your Finesse modifier (minimum 1). When a creature you can see makes an Instinct or Finesse roll, you may spend 1 Debug Token after the roll to let them reroll one die from that roll. (They must keep the new result.) You regain all spent Debug Tokens when you complete a long rest. </p><p>As a short rest move, you may gain additional Debug Tokens equal to your Finesse modifier.</p>*
